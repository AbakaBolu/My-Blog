这个博客使用 **Jekyll** 生成，托管在 **GitHub Pages** 上。

## 工作流程

1. 我用 Markdown 写文章，放进 `_posts` 文件夹；
2. 把修改推送（push）到 GitHub 仓库；
3. GitHub Pages 自动运行 Jekyll，把 Markdown 转换成 HTML；
4. 生成好的网页发布到 `https://用户名.github.io`。

整个过程完全免费，也不需要自己维护服务器。
