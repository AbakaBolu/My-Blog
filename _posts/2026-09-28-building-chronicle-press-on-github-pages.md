在决定重构个人博客时，我给自己设定了一个明确的目标：**不做千篇一律的程序员模板，而是把它当作一本在线发行的独立杂志来设计**。

这篇构建日志记录了本站（代号 *Chronicle Press*）在视觉、排版与动效工程上的关键取舍。

## 一、色彩系统：用温暖纸感取代冷白

绝大多数默认网页模板使用 `#FFFFFF` 纯白背景配 `#000000` 纯黑文字。这种极高对比度在暗室或长文阅读时极易产生眩光。

我们采用了以 `#FAF9F5`（暖象牙纸白）为基底、`#F3F1E9`（浅米色卡片）为次级容器、`#E5E2D8` 为细分割线的色彩体系：

```css
:root {
  --bg-page: #FAF9F5;
  --bg-card: #F3F1E9;
  --bg-card-hover: #ECE9DF;
  --text-primary: #191919;
  --text-secondary: #77756E;
  --border-subtle: #E5E2D8;

  /* 低饱和人文点缀色 */
  --accent-terracotta: #C66B4E;
  --accent-slate: #5A7D9A;
  --accent-sage: #588B60;
  --accent-ochre: #D8B45A;
}
```

## 二、克制的微交互与无障碍设计

好的前端动效应当像翻动书页一样自然，永远不抢夺正文的注意力：

1. **首屏渐次入场**：宣言、主视觉与最近文章以 `14px` 的轻微上移和 `600ms` 的 `cubic-bezier(0.22, 1, 0.36, 1)` 缓动依次显现，错开 `80ms`。
2. **居中标志的滚动折叠**：当页面向下滚动超过阈值，顶部居中的完整署名 `ABAKA\BOLU` 平滑收拢为简写标志 `A\B`，既节省纵向空间，又不会引起任何布局抖动（CLS = 0）。
3. **尊重系统偏好**：当检测到用户开启 `prefers-reduced-motion: reduce` 时，所有位移与背景慢速动画自动降级为瞬时静态呈现。
