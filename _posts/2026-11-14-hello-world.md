这是博客的第一篇文章。每篇文章就是 `_posts` 文件夹里的一个 Markdown 文件，文件名格式必须是 `年-月-日-英文标题.md`。

## 为什么写博客

> 写作是把模糊的想法变清晰的过程。

写博客能帮我：

1. 整理思路，把零散的想法固定下来；
2. 记录成长，回头看能看到自己的变化；
3. 与他人交流，结识志同道合的人。

## Markdown 常用语法示例

**粗体**、*斜体*、[链接](https://pages.github.com/)、`行内代码`。

```python
def hello(name: str) -> str:
    return f"你好，{name}！"

print(hello("世界"))
```

| 语法 | 效果 |
|------|------|
| `# 标题` | 一级标题 |
| `- 项目` | 无序列表 |
| `![描述](图片地址)` | 插入图片 |
