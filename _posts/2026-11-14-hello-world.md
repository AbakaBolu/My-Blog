每隔一段时间，我都会对自己的物理桌面和电脑里的软件做一次彻底的“断舍离”。我越来越深刻地体会到：**注意力并不是某种可以无限透支的资源，它高度依赖于我们所处的环境秩序。**

## 一、物理桌面的“三件套”原则

在开始写代码或写文章之前，我的桌面上通常只保留三样东西：显示器、机械键盘，以及一杯温水或手冲咖啡。

> 视野里每多一件与当前任务无关的物品，大脑后台就会多驻留一个微小的轮询进程。

1. **把手机放在伸手够不到的房间另一侧**：仅仅是“需要站起来走五步才能拿到手机”这一个微小的物理摩擦力，就能过滤掉 90% 的无意识亮屏。
2. **固定每日的深度写作时段**：早晨八点半到十点半，不打开任何即时通讯软件，只面对编辑器里的纯文本。

## 二、数字工具的克制选型

在尝试过无数复杂的笔记系统和插件生态之后，我最终回到了最朴素的组合：

| 场景 | 工具选择 | 选择理由 |
| :--- | :--- | :--- |
| **代码与写作** | VS Code / 极简模式 | 隐藏侧边栏与状态栏后，只剩纯粹的字形与留白 |
| **文稿存储** | 本地 Markdown + Git | 跨平台、可追溯、二十年后依然可读 |
| **文献阅读** | 纸质书 + 方格手账 | 保留翻页的空间记忆与手写批注的阻尼感 |

当我们不再花费大量时间去“配置工具”，真正的思考与创作才刚刚开始。
